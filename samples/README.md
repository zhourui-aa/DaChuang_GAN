# 验证样例（虚拟论文）

用于验证「上传 → 解析 → 检测 → 证据」全链路。文件均为虚构内容。

## 文件

| 文件 | 风格 | 预期结果 |
|---|---|---|
| `20230415_王雪_读书报告.docx` | 模板化 AI（排比、套语、重复短语） | 中关注（约 70%） |
| `20230425_赵天宇_读书报告.txt` | 同上（txt 版，验证 txt 解析） | 中关注（约 70%） |
| `20230418_陈思远_读书报告.docx` | 人机混合（一半套话一半个人经验） | 低关注（约 25%） |
| `20230421_孙悦_读书报告.docx` | 人工写作（口语、具体细节、句长起伏大） | 低关注（约 0%） |

> 实测值随阈值版本变化；上表为当前 `v1` 配置下的结果。

## 怎么用

1. 登录 `http://localhost:5173`（`lijianguo / 123456`）
2. 教师工作台 → 课程选「智能制造技术导论」→ 作业选「《智能制造技术导论》读书报告」
3. 点「批量上传」→ 把 `samples/` 下 4 个文件一起拖进去 → 上传并检测
   - 批量模式会**按文件名中的学号自动匹配学生**
4. 等几秒后刷新列表，点「查看详情」看特征雷达与可溯源证据

> 注意：同一学生对同一作业只能提交一次（去重）。若需重跑，先 `make db-reset`，
> 或换一个作业 / 学生。

## 设计意图

这 4 份特意做成不同「写作指纹」，用来验证 6 个特征是否真的能区分：

- **模板化文本**：句长均匀、套语密集、短语重复 → 困惑度(压缩比)低、改写痕迹高、行文轨迹平滑、词汇丰富度低、结构规律性高
- **人工文本**：句长起伏大、用词多样、有具体细节与第一人称 → 各维度都往「不可疑」偏

## 已知的 P0 近似（见 `detect_configs.feature_dsl.notes`）

- **困惑度**：用 gzip 压缩比近似（真实困惑度需本地模型 logprob）
- **行文轨迹**：用相邻句实词 Jaccard 平滑度近似（真实方案是 embedding 语义相似度）
